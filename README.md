## About

A software Elevator Control System (ECS) that controls 4 elevators in a 10-floor building. Supports car and hall floor requests, door safety (obstruction and weight sensors), fire alarm recall, firefighter manual control, and a building manager control panel. See `/resources` for the full Requirements Definition Document (RDD) and future design docs.

## Repo structure

- `/resources` - RDD, SRS, design diagrams, meeting notes
- `/src` - Java source (Maven project)
